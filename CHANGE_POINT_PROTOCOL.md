# Finite restart watch: preregistered disjoint real-model audit

**Frozen before the first new model call in CI.** Research only. Keep the original [120-question result](REAL_MODEL_WATCH_RESULTS.md) intact, including its 1/6 synthetic detections. This study makes no claim of live customer drift, production safety, or a novel statistical theorem. If the monitor misses the intervention or alarms on the observed baseline, record that result without tuning this protocol.

## Data and independent scoring

- Official Stanford SQuAD v1.1 development JSON, SHA-256 `95aa6a52d5d6a735563366753ca50492a658031da74f301ac5238b03966972c9`. Sort answerable questions by SHA-256 of question ID as in `load_questions`; take offsets **320–439** (120 requests). These question IDs do not overlap the previous watch's 200–319 or earlier model work's 0–199. Articles can still overlap. The public dataset is not a hidden holdout.
- Baseline: pretrained `distilbert/distilbert-base-cased-distilled-squad`, immutable resolved revision, same grading rubric and source-offset verifier as the previous audit. Gold is used only after each inference. Every requested call, including execution failure or abstention, stays in the denominator and counts as an error. Published human answers provide reference labels; the repository grader has not received an external audit.
- Predictable groups are source context length at most 600 characters versus longer, assigned before inference. Error means no verified source-backed answer with normalized token F1 ≥ 0.5. Error target **0.50** is intentionally a severe-deterioration stress threshold, not a product quality requirement. Familywise anytime alpha **0.05**.

## Frozen monitor and decision rule

- Run both the existing from-start six-bet watch and the new finite restart watch on each identical ordered stream. The restart schedule uses global one-based starts **1, 21, 41, 61, 81, 101**, and horizon **120**. Each of the six starts monitors the aggregate and both predeclared groups, for **18** tests. Each fixed started mixture is a nonnegative supermartingale under the conditional null `P(error_t=1 | past) ≤ 0.50` for the slice, provided the group is known before its outcome. Crossing threshold is **18 / 0.05 = 360** for each component (log threshold ≈ 5.886). Ville's inequality and a union bound give familywise probability ≤ 0.05 of any crossing under the *joint conditional null*. All 18 tests consume budget even if a start has not occurred yet. This is established sequential-testing mathematics, not a guarantee of detection.
- Primary descriptive results: observed baseline alarm yes/no; in a real-model **retrieval intervention**, earliest restart and from-start alarm request, delay from intervention onset, or miss by 120. A pre-onset alarm is disclosed separately and never counted as detecting the intervention. No favorable threshold is selected after outcomes are seen.
- Secondary stress results: on the real baseline outcome stream, after **25, 55, or 85** requests, flip each originally correct post-onset label with fixed probability **0.5 or 1.0** using `Random(20261020 + onset*10 + int(probability*100))`. These six are **synthetic label changes, not model predictions**. Record flips, alarm position, pre-onset alarms, detection delay and missed scenarios for both monitors. A baseline alarm or negative comparison stays in the report.
- Synthetic diagnostic: **400** seeded IID Bernoulli(0.5) streams with the real question-group schedule, seeded `20261020`, run through both watches. Report alarm counts. These are software checks under a synthetic conditional null, not a measured false-alarm rate for the model.

## Actual model-call intervention

After request **55**, call the *same* resolved model on the remaining **65** questions with only the first **128 characters** of each original source context. The rule does not inspect gold answers or model correctness and leaves question order and group assignments intact. Score each new output against the published answers, and verify offsets against the context actually supplied. Prefix outcomes are copied from the 120 baseline calls. Thus the intervention stream has one actual-model outcome per question and 65 additional genuine calls, but its retrieval damage is **deliberate**, not natural deployed drift. Failures and abstentions are errors. Report number of additional calls, errors, certificates and failures. Store its exact ordered binary trace.

## Evidence and claim boundary

CI stores a hash of this frozen protocol, a JSON report, and the baseline and intervention JSONL streams. It independently recomputes the new watch on both stored traces and checks the common ordered-outcome fingerprints, model revision, group definitions, no automatic rollout flag and declared call counts. The report is unsigned research evidence. Shared articles, incorrect grading, selective feedback, missing outcomes, post-hoc schedule choice, and manipulation of the ledger can invalidate a deployed interpretation. No alarm is not proof of safety. The production dual-evidence gate continues to accept only its existing signed watch format and independently anchored current ledger.
