# Frozen two-stage calibrated restart audit

**Status:** committed with executable code before the new real-model calls. This is an exploratory research study motivated by the negative [previous change-point result](CHANGE_POINT_RESULTS.md), where a fixed 50% target missed a deliberate retrieval failure. Its model, method, error budgets, data offsets, intervention and evaluation criteria are fixed here. Report any failure without changing them on these questions.

## Two reserved, disjoint question sets

- Dataset: official public Stanford SQuAD v1.1 development JSON, SHA-256 `95aa6a52d5d6a735563366753ca50492a658031da74f301ac5238b03966972c9`. Apply the existing SHA-256 question-ID sort. **Calibration offsets 440–559**, 120 requests; **evaluation offsets 560–679**, 120 requests. Earlier watch experiments used 200–439. Question IDs are disjoint, though articles may overlap and invalidate IID assumptions.
- Model: `distilbert/distilbert-base-cased-distilled-squad`, pinned revision `564e9b582944a57a3e586bbb98fd6f0a4118db7f`; real CPU inference with the same source-offset proof and human-gold normalized F1 ≥ 0.5 correctness rubric as the preceding audits. Published gold is used only after each call. An abstention, unsupported answer or failed call remains an error in its ordered denominator. The repository's grading code has not received an external audit.
- Groups: original source context length **at most 600 characters** (`short_source`) versus longer (`long_source`), assigned before inference. Aggregate and both groups are monitored. No exclusions based on observed outcomes.

## Calibration and monitoring budget

1. On the 120 calibration model outcomes, calculate each slice's `n`, error count and empirical rate. Require at least **20** outcomes per slice. Set its upper error target to `min(1, empirical_rate + sqrt(ln(3/0.025)/(2n)))`. If any bound is 1 or support is inadequate, mark the complete monitor **inconclusive**; do not silently omit a group or substitute a favorable target. This is a one-sided Hoeffding bound with calibration failure budget **δ = 0.025**, divided by a union bound over the three slices. Its coverage requires IID Bernoulli calibration errors within each slice; article sharing can break that premise.
2. On a separate 120-question evaluation stream, use the existing fixed six-bet error e-process restarted at global one-based request positions **1, 21, 41, 61, 81, 101**. Apply the slice-specific calibrated targets. Allocate **monitoring α = 0.025** over all **18** predeclared start × slice components, including starts beyond the current prefix. Alarm threshold is `18 / 0.025 = 720` (log ≈ 6.579). The total budget is **δ + α = 0.05**.
3. Under a stationary calibration-to-monitoring error model, IID calibration within each slice, predictable groups, complete independent labels, and the joint conditional monitoring null, the union bound controls the probability of *any false alarm* by 0.05. Those conditions have **not** been established for the public benchmark or a customer workflow. The code's output is unsigned research evidence and does not connect to the release gate. A no-alarm result says nothing about safety.

## Actual intervention and comparisons

- Collect all 120 ordinary baseline evaluation calls. Then, after **request 55**, make **65 additional calls** to the same pinned model and question sequence using only the first **128 characters** of each original source context. This deterministic rule ignores gold and model outcomes. Verify source offsets against the context actually supplied, and score against published human answers. The intervention stream reuses the first 55 baseline outcomes, so there is one actual-model outcome for every one of its 120 requests. It is a **deliberate retrieval failure, not natural live-model drift**.
- Primary descriptive criterion: calibration ready, no alarm on the ordinary baseline, and an alarm **after** the intervention onset by request 120. Report earliest alarm request and delay; a pre-onset alarm never counts as detecting the intervention. Run the previous fixed-50% restart monitor on these **same evaluation outcomes** for an apples-to-apples descriptive comparison. If either fails, record that directly.
- Secondary stress: apply six explicitly **synthetic** correct-to-error suffix flips to the ordinary real-model evaluation trace after requests **25, 55, 85**, with probabilities **0.5** and **1.0** using `Random(20261021 + onset*10 + int(probability*100))`. Record flips and first crossing; these labels are not additional model predictions. No post-hoc threshold, bet, start, subgroup or source cap changes are permitted on this set.

## Archiving and interpretation

CI stores the SHA-256 of this protocol, aggregate reports, and ordered calibration, ordinary evaluation and intervention binary traces. An independent recomputation step checks calibration targets, both monitored traces, outcomes' digests, disjoint offsets, model revision, intervention call count and no-rollout state. No raw questions, passages or answers are archived. This public task, the correlated articles and the deliberate intervention cannot establish production sensitivity, statistical validity in deployment, commercial value or a guaranteed detection horizon. The complete results are preserved even if the primary criterion fails.
