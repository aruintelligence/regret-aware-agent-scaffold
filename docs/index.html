03 / Proof-carrying answers · research preview

Show the source.
Or choose not to answer.

ĀRU's experimental grounding contract only accepts short AI answers that can be verified as an exact source span. A certificate records the source fingerprint and character offsets so another system can check the claim without trusting the model's confidence.

A narrow guarantee that can be checked.

If a model generates an answer absent from the passage, the contract abstains. The research report measures how many answers were withheld and how much accuracy was lost or retained.

What this does not prove: that the source is trustworthy, the answer is relevant, or the statement is factually true. Those are separate research and engineering requirements.

A real 135M-parameter model has completed 120 public-data calls across initial and matched evaluations. The matched restrictive prompt scored 21.50% F1 versus 23.53% for the direct prompt; no quality advantage was demonstrated.

04 / Sovereignty by design

Evidence before expansion.

Automatic rollout is disabled.

A statistical screen can recommend further investigation, never silently deploy a new policy. The local gateway requires an API key and an explicit research opt-in header. Enterprise-grade authentication, encryption, retention controls and security audits remain future work.

New / Sovereign Source Registry

Permission is part of the evidence.

ĀRU's local research registry records purpose-limited, expiring, revocable operator-attested source grants without storing the raw document. When enabled, the QA server checks the exact authorized source and owner before executing a model.

An independently retained checkpoint can detect rollback of previously anchored revocations. This is not verified human consent, user authentication, or enterprise-grade access control.
