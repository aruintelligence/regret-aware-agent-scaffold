01 / Measured, not imagined

A real benchmark.
A result you can reproduce.

Two deterministic sentence-retrieval algorithms were evaluated against human-annotated answer locations on 2,000 questions from the Stanford SQuAD v1.1 development set. Neither algorithm saw the gold answers.

2,000Human-annotated questions
78.5%Lexical baseline accuracy
82.1%Challenger accuracy
+3.6 ppMeasured sentence-retrieval gain
Baseline · token overlap78.5%
Challenger · IDF + proximity82.1%

Exploratory 95% article-cluster interval for the difference: +2.47 to +4.61 percentage points (48 articles).

Truth includes limitations

We show the misses, too.

The challenger performed worse in one observed topic. ĀRU flagged the regression rather than declaring universal superiority.

Victoria (Australia): baseline 72%; challenger 64% on 25 questions. This small subgroup result is exploratory.

MEASUREMENT

Counterfactual evidence

IPS, SNIPS, doubly robust diagnostics, propensity checks and uncertainty estimates.

TRACEABILITY

Evidence passports

Local SQLite logging, HMAC audit chains, and reproducible HTML and JSON reports.

CONTROL

Regret-aware safeguards

Detect missing outcomes, weak support, domain regressions and adversarial topic-mix risk.

03 / Sovereignty by design

Evidence before expansion.

Automatic rollout is disabled.

A statistical screen can recommend further investigation, never silently deploy a new policy. The local gateway requires an API key and an explicit research opt-in header. Enterprise-grade authentication, encryption, retention controls and security audits remain future work.
