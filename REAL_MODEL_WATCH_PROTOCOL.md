# ĀRU real-model risk-watch audit: fixed protocol

**Status:** prospective research exercise on a public development dataset. This protocol and code are committed before the corresponding PR #7 real-model CI run. It is not a customer validation, a production monitor, or an external certification.

## Fixed before running the model

- **Data:** official Stanford SQuAD v1.1 development JSON, SHA-256 `95aa6a52d5d6a735563366753ca50492a658031da74f301ac5238b03966972c9`. Sort answerable questions by SHA-256 of their published question ID, then take offsets **200–319** (120 requests). These IDs do not overlap this repository's earlier 0–199 model exercises. This is a public development split, not a hidden holdout. The dataset is downloaded during CI and is not redistributed.
- **Model:** real pretrained `distilbert/distilbert-base-cased-distilled-squad`, with fast-tokenizer original source offsets, safetensors weights and no remote custom code. Resolve and record its immutable model revision. Call the model once per selected question; do not give it the published answers before inference.
- **Independent label source:** published human answer annotations. This repository's normalized token-F1 scorer runs after each model call. Correct means a **verified source-backed answer with F1 at least 0.5** versus any published gold answer. Missing outputs, failed model calls and abstentions count as errors in the full requested stream; infrastructure failure count is disclosed. The grader implementation itself has not received external audit.
- **Ordering and groups:** keep the preselected SHA-sort order. Source passage length **at most 600 characters** maps to `short_source`; longer maps to `long_source`. Group assignment occurs before inference and cannot use the model's answer or gold result.
- **Monitor:** binary error target **0.50**, familywise anytime alpha **0.05**, default six-bet grid, both groups and aggregate. The high target is chosen to examine severe deterioration; it is not a commercial quality goal. Use the same code and settings for the baseline and each stress scenario. Record the ordered event JSONL, its SHA-256 fingerprint in the watch report, subgroup alarms and earliest alarm position in global request order. An observed alarm is reported as found; do not change the target after viewing it.
- **Controlled stress:** preserve the actual graded baseline. After 30, 60 or 90 observed requests, flip each originally correct post-onset label to error using fixed seeded probabilities 0.5 or 1.0. These **six altered suffixes are synthetic**, not new model calls or observed deterioration. Report flips, alarms before the change, first alarm after the change, delay in requests, and no alarm by 120. A pre-onset alarm is not counted as detecting the injection.
- **Simulated conditional null:** 200 seeded independent Bernoulli(error=0.50) streams follow the real stream's group schedule. The fraction alarming is a software/statistics diagnostic under this synthetic null, **not** an estimated false-alarm rate for the real model or correlated SQuAD articles.

## Interpretation and boundaries

The real trace measures errors made by one actual pretrained model on these public, human-annotated questions. The counterfactual deterioration is produced by changing labels in a replay; it does not show a model actually becoming worse over time. One real trace cannot estimate power, false-alarm frequency, or detection delay under customer distribution shift. Shared articles, grader mistakes, delayed/missing customer feedback and selection effects can violate the e-process conditional-null assumptions. An absence of alarm does not prove an error ceiling; an alarm warrants human investigation.

The audit artifact has event order, binary labels, group assignments, aggregate statistics, protocol hash and resolved model revision, but no passages, questions, gold spans or model answers. This is an **unsigned research artifact**, not an independently controlled monitoring ledger or a risk-qualified static policy. The separate dual-evidence release gate still requires its own signed calibration, signed current watch and independent source proof with matching model, rubric, groups and target. No automatic rollout is permitted.
